# Quantum Circuit Library using Qiskit

## Project Overview

The **Quantum Circuit Library** is a Python-based application developed using **Qiskit** that demonstrates some of the most fundamental concepts of Quantum Computing. The program allows users to create, simulate, and visualize different quantum circuits through a simple command-line menu.

The project focuses on three important quantum states:

- Superposition
- Bell State (Entanglement)
- GHZ State (Multi-Qubit Entanglement)

For each circuit, the program displays the circuit diagram, statevector amplitudes, measurement outcomes, and histogram visualization, helping users understand how quantum circuits behave before and after measurement.

## Installation

### Step 1: Clone the repository

```bash
git clone https://github.com/yourusername/Quantum-Circuit-Library.git
```

or simply download the project folder.

---

### Step 2: Install Python

Python 3.10 or above is recommended.

Verify installation:


Install Qiskit and other required libraries.

```bash
pip install qiskit
```

Or install everything together:


## Running the Program

Execute the Python file:

```bash
python quantum_circuit_library.py
```

The program will display the following menu:

```
Quantum Circuit Library

1. Superposition
2. Bell State
3. GHZ State
4. Exit
```

Choose any option to simulate the corresponding quantum circuit.

## Quantum Circuits Included

### 1. Superposition

A Hadamard gate is applied to every qubit, placing each one into an equal superposition of |0⟩ and |1⟩.

Expected result:

```
|0⟩ ≈ 50%
|1⟩ ≈ 50%
```

---

### 2. Bell State

A Bell State is generated by applying:

- Hadamard Gate
- Controlled-NOT Gate

This creates quantum entanglement between two qubits.

Expected measurement outcomes:

```
00 ≈ 50%
11 ≈ 50%
```

The states **01** and **10** should not appear.

---

### 3. GHZ State

The GHZ State extends Bell-state entanglement to multiple qubits.

Example for three qubits:

```
(|000⟩ + |111⟩)/√2
```

Expected outcomes:

```
000 ≈ 50%
111 ≈ 50%
```
